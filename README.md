# شەوی مەخمەلی: نهۆمی حەڤدەیەم | Midnight Velvet: The 17th Floor

A mobile-first, bilingual (**Sorani Kurdish RTL** & **English LTR**) Romantic Thriller & Dating-Sim Visual Novel built with React, TypeScript, Vite, Framer Motion, Web Audio API, and real-time HTML5 weather/lighting shaders.

## Features
- **Deep Branching Romance & Mystery:** 4 Chapters + Prologue + **5 Unlockable Endings** (Layla True Romance, Layla Bittersweet Temptation, Celine True Romance, Celine Daybreak Promise, and Secret Dual Ending).
- **Dynamic Relationship & Chemistry Engine:** Tracks Layla Affection, Celine Affection, Chemistry, Trust, Boldness, and story flags that dynamically alter future dialogue lines.
- **8 Custom Anime / Webtoon Illustrations & Unlockable CG Gallery** with fullscreen mobile lightbox.
- **Full Visual Novel Reader Suite:** Anti-jump Typewriter text, Auto-forward, Skip, Dialogue Backlog, 6 Save/Load slots + Crossroads Checkpoint, Procedural Rain & Jazz/Piano Synth Audio, and an in-app **Mobile Scene Studio**.

## Run Locally
```bash
npm install
npm run validate:story
npm run dev
```
